# Ocean Glass（海雾玻璃）全站视觉与动效设计

## 背景与目标

本项目需要将整体视觉升级为“海洋动态”主题，并达到“非常惊艳”的观感，同时保持可读性、可维护性与全站一致性。

本设计文档聚焦于 UI 视觉、动效签名与落地方式，不包含具体实现任务拆解。

## 成功标准（验收口径）

- **第一眼惊艳**：进入任意页面 1 秒内能感受到“海雾玻璃 + 海洋动态”的主题氛围。
- **全站一致**：首页、采集、看板、后台页面采用同一套背景层、玻璃层、色彩与动效语言。
- **不影响使用**：正文与表格可读性稳定；交互反馈明确；动效不干扰操作。
- **性能可控**：在常见笔记本浏览器上保持顺滑；低端环境可自动降级（减少/关闭动画与滤镜）。
- **可访问性**：支持 `prefers-reduced-motion`；亮色模式可用且不刺眼。

## 设计决策（已确认）

### 视觉气质

- 主方向：**D 海雾玻璃（Ocean Glass）**
- 覆盖范围：**全站统一背景**
- 动效强度：**微动沉浸**

### 实现路径

- 方案：**A 纯 CSS / Framer Motion**
- 原则：
  - 背景动效以 CSS 动画与渐变层叠实现
  - 交互动效（hover/focus/route transition）可用 Framer Motion（项目已存在 framer-motion 依赖）
  - 不引入 Canvas/WebGL 作为默认路径，避免全站维护与兼容成本

### 配色（暗色主）

- 主高光（Primary Glow）：`#22d3ee`（ice cyan）
- 次高光（Secondary Glow）：`#38bdf8`（sky blue）
- 雾灰（Mist Neutral）：`#94a3b8`（slate）
- 深海底色（Abyss Base）：建议以 `#0b1220` / `#070b12` / `#020617` 作为基底分层

### 动效签名（全站统一）

- 选择：**A 雾漂移 + 扫光**
- 具体表现：
  - 两层雾团（radial fog）缓慢漂移，产生“海雾流动”
  - 一条低频斜向扫光（scanline）周期性掠过，产生“玻璃反射”感

### 亮色模式策略

- 亮色模式：**暗色为主 + 亮色简版**
- 亮色简版原则：
  - 保留玻璃质感与品牌色（更克制）
  - 明显降低背景动效与光晕强度，避免亮底眩光与阅读疲劳

## 视觉系统（Tokens）

### 背景层（OceanBackdrop）

背景由 3 组层叠构成（可全站固定）：

1. **深海基底渐变**
   - 135° 方向深色渐变，提供稳定底噪与空间感
2. **雾团漂移（Fog A / Fog B）**
   - 两个 radial gradient 雾团，`mix-blend-mode: screen` 或等效方案
   - 低频位移 + 轻微旋转，形成“海雾”流动
3. **扫光（Scanline）**
   - 细线（1–2px）长条渐变，倾斜（约 -8° ~ -12°）
   - 低频横向位移，透明度在低值区间波动

推荐参数（暗色默认）：
- Fog A：周期 10s，ease-in-out，无限循环
- Fog B：周期 13–14s，ease-in-out，无限循环（与 Fog A 不同步）
- Scanline：周期 7–9s，ease-in-out，无限循环
- 光晕透明度：常态 0.10–0.28 区间（随页面密度微调）

### 玻璃层（Glass Surfaces）

所有“承载内容”的容器统一玻璃配方：

- 背景：`rgba(255,255,255,0.06~0.16)` 的上下渐变
- 边框：`rgba(255,255,255,0.10~0.18)` 细边
- 高光：顶部轻微高光线（可用 `inset` 阴影模拟）
- 模糊：`backdrop-filter: blur(10~14px)`（无则降级为半透明+阴影）
- 阴影：偏深、软（形成“漂浮在海雾上”的层次）

层级建议：
- Level 1：页面主容器 / 面板
- Level 2：卡片 / 次级容器
- Level 3：弹窗 / 下拉 / Popover（更强阴影、更清晰边界）

### 组件强调（CTA 与交互）

“惊艳”主要来自交互细节与质感：

- 主按钮：
  - 采用冰蓝青渐变或轻微发光外圈
  - hover：轻微发光增强 + 1px 上浮（或阴影加强）
  - active：发光回落、按下反馈明确
- 输入/聚焦态：
  - focus ring 采用 `#22d3ee`，但控制强度，避免刺眼
  - 结合玻璃边框亮度微调

## 动效规范

### 全站动效（背景）

- 背景动效必须低频、低幅度，目标是“沉浸”，而不是“花”
- 同一套动效参数适用于所有路由，避免风格漂移

### 交互动效（组件）

- 基础时长：160–220ms（按钮、输入、卡片 hover）
- 页面进入/路由切换：200–320ms（可选，保持克制）
- 缓动建议：`ease-out` 为主；需要“流体感”时可用更柔的曲线

## 可访问性与降级

### Reduced Motion

- 当 `prefers-reduced-motion: reduce`：
  - 关闭 fog 漂移与 scanline
  - 保留静态渐变与玻璃层（仍能保留主题）

### 亮色简版

- 亮色模式降低：
  - fog 对比度（透明度与饱和度下降）
  - scanline 透明度（更低或关闭）
  - glow 色偏灰（避免荧光感）

### 滤镜降级

- 不支持 `backdrop-filter` 的浏览器：
  - 使用更高的透明度 + 更清晰的边框 + 更明显的阴影来补偿层次

## 落地范围（前端）

### 全局位置

- 在 App Router 根布局注入背景层与主题 tokens
- 全站页面内容保持在玻璃容器之上，统一 padding/栅格/层级

### 关键页面

- 首页 / 采集页 / 看板 / 后台页：统一容器层级与标题体系
- 图表与表格：优先保证可读性与对比度，避免过多背景穿透

## 设计边界（防止“越做越花”）

- 不引入高频粒子、强闪烁、强对比霓虹作为默认体验
- 背景动画不允许影响文本阅读（必要时内容区可加更不透明的玻璃层）
- 所有“惊艳点”优先来自：层次、质感、微交互，而不是大幅动画
