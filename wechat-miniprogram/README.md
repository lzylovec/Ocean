# Ocean 微信小程序端

这个目录是 Ocean 项目的原生微信小程序前端，直接复用现有 FastAPI 接口，不依赖额外构建工具。

## 覆盖页面

- 首页：健康状态、关键指标、快捷入口、最近记录
- 采集页：选图、上传、创建异步任务、轮询结果
- 任务页：查看队列、筛选、取消、重试、查看详情
- 看板页：治理指标、潜点风险、最近入库记录
- 复核页：查看垃圾身份证、按状态筛选、进入详情复核
- 详情页：任务详情、垃圾身份证详情

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录指向当前目录：`wechat-miniprogram`。
4. `AppID` 可以先使用 `touristappid` 调试。

## 后端地址

小程序会按运行环境自动选默认地址：

```text
开发者工具 / 模拟器: http://127.0.0.1:8000
真机调试:           http://192.168.0.26:8000
手机预览包:         必须使用 HTTPS 公网域名
```

- 如果你的电脑 IP 变了，执行 `scripts/sync-wechat-api-base.sh` 会自动把“小程序真机调试默认地址”更新成当前局域网地址。
- 真机或正式发布：必须改成微信后台已配置的 `HTTPS` 合法域名。

同时建议把后端 `PUBLIC_BASE_URL` 也配置成同一个外网地址，否则图片 `publicUrl` 仍可能指向本地地址。

## 本地联调建议

真机调试时，不要再用默认的 `uvicorn` 启动方式，因为它默认只监听 `127.0.0.1`。请改用：

```bash
scripts/run-wechat-api.sh
scripts/run-wechat-worker.sh
```

这个脚本会自动：

- 用你当前 Mac 的局域网 IP 作为 `PUBLIC_BASE_URL`
- 让 FastAPI 监听 `0.0.0.0:8000`

worker 也建议用同样思路启动，否则任务写入数据库时，增强图链接仍可能落成 `127.0.0.1`。

## 手机预览为什么连不上

微信开发者工具里的“手机预览”不是“真机调试”。

- `真机调试` 可以用局域网地址联调
- `手机预览` / `体验版` / `发布版` 需要走微信后台配置过的 `HTTPS` 合法域名

也就是说，`http://192.168.0.26:8000` 这种地址即使真机调试能用，手机预览包依然不能用。

如果你要让“手机预览”可用，需要：

1. 准备一个可公网访问的 `HTTPS` 域名
2. 在微信小程序后台把它配置到 `request 合法域名`
3. 把 `wechat-miniprogram/utils/runtime-config.js` 里的 `PREVIEW_API_BASE_URL` 改成这个域名
4. 同步把后端 `PUBLIC_BASE_URL` 也设成同一个 `HTTPS` 域名

如果使用微信开发者工具直连本机接口，通常还需要：

- 在开发者工具里关闭“校验合法域名、web-view、TLS 版本以及 HTTPS 证书”
- 保证手机和电脑在同一个局域网
- macOS 防火墙没有拦截 Python / 8000 端口
- 或者把后端暴露成一个可访问的 HTTPS 域名

## 说明

- 小程序端复用了 Web 端同一套 API，没有改动后端业务链路。
- 这是移动端 MVP，重点保证上传、轮询、看板和复核能跑通。
